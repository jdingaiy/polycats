# Polycats

离线 SVG 多边形小猫画板。黑白页面显示画板与四个按钮：画多边形、随机形状、换一只猫、导入图片。导入后显示“显示图片叠底”开关。小猫保留彩色花纹，画板仅标注自动匹配的“××状”。

## 使用

首次安装（Python 3.11～3.13，已用 3.12 验证）：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm start
```

服务启动在端口 8000；在浏览器打开本机的该端口即可使用。也可运行 `.venv/bin/python server/serve.py --port 8000`，无需 Node 启动服务。`npm run build` 输出单文件画板，但直接离线打开 HTML 无法调用图片处理服务。`npm test` 执行 JS 检查，`.venv/bin/python -m unittest discover -s tests -p test_upload.py` 执行图片处理测试。

## 图片导入和叠底

支持 JPG、PNG、WebP、HEIC/HEIF；单文件不超过 32 MB。点击导入后用 BiRefNet Lite 本地去背景，取最大前景区域并简化成最多 15 个顶点。首次使用会从 rembg 官方发布地址下载约 224 MB 的权重，遵循库的校验流程；之后复用 `.cache/rembg` 模型缓存和服务内模型实例。

已有透明背景的图片直接使用其 alpha。上传图片不会发送至第三方推理服务，也不在服务端持久保存。预览只在浏览器当前页面保留。复杂多主体图片可能选错区域，目前没有点选目标功能。

导入完成默认打开图片叠底。使用完整的已校正方向图片作为底图，照片与多边形共享同一个居中缩放变换，开关不改变轮廓。叠底打开时小猫略透明，方便比较。拖动顶点时底图固定不变；换猫保留底图；生成随机轮廓或完成新绘制后隐藏叠底。失败的上传保留已有场景。可重复导入同一个文件。

前端只增加导入按钮和导入后的开关。当前服务为本地开发服务，提供同源 `/api/segment`；不是可公开访问的托管网站。

逐点绘制，点击起点或 Enter 完成；Backspace 撤销，Esc 取消。拖动顶点或整条边调整轮廓；双击边缘增加顶点，双击内部微调脸的位置。编辑控制点在鼠标悬停或触屏操作时显示。

## 随机轮廓

角度限制已经取消。不显示最小角度，不补截角短边。随机轮廓从姿态轮廓扰动与自由径向多边形生成；仅检查边长、面积和自交以维持有效编辑，允许锐角、凹口和任意朝向。此前的颜色连通区抠图已移除；当前导入功能使用真实 BiRefNet Lite。

## 绘制

后台恢复 50 个姿态预设（26 个基础动作加 24 个连续姿态变体），用于轮廓对齐、镜像和匹配。预设库不在交互页面展示，也不提供姿势任意切换。匹配存在歧义，不代表真实动作识别。

眼睛与嘴巴独立随机组合，眼型支持睁眼、轻闭眼、眨眼、流泪和流汗。吐舌、泪滴、汗滴独立随机附加；好奇眼型保持三瓣嘴。面纹按猫的毛色和头部结构生成：虎斑从耳根延伸至眉间、眼角和脸颊；奶牛/三花使用连接耳根的色素分区；纯色猫只保留自然明暗。移除孤立的 W、三条直线、菱形及额头帽斑。无参数与五官文字控制器。

面部底色使用低透明度渐变融入身体，保留有意的奶牛、三花等色块；喷涂图层继续用 SVG 高斯柔焦；身体使用弯曲分叉条纹或深浅斑块。身体纹理在头部附近渐隐，避免随意穿过五官。轮廓内侧新增随光照方向变化的柔和渐变，仍裁剪在原始多边形内。导出工具栏已移除；当前提供互动和图片叠底。

## 验证

测试覆盖模板匹配、旋转/镜像、头部余量、自由随机轮廓、花色与额纹、独立眼口和吐舌/流泪/汗滴组合。Chromium 在断网模式载入独立 HTML，检查四个按钮、导入后开关、真实 HEIC 上传、14 点轮廓、底图变换对齐、重复导入、失败保留场景、换猫保持轮廓、自绘、实时拖动和手机布局。

最近渲染修正：身体花纹沿模板躯干布局，脸部区域用连续径向衰减过渡。所有模糊滤镜使用足够大的画布坐标范围，避免对象包围盒截断产生矩形接缝。重点色用渐变色素而非完整深色椭圆。内侧轮廓阴影由剪影透明度推导，不使用沿边缘描线。
