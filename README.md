# Polycats

离线 SVG 多边形小猫画板。黑白页面显示画板与四个按钮：画多边形、随机形状、换一只猫、导入图片。导入后显示“显示图片叠底”开关。小猫保留彩色花纹，画板仅标注自动匹配的“××状”。

## 使用

首次安装（Node 24；本地静态服务使用 Python 3）：

```sh
npm ci
npm start
```

默认端口 8000。`npm run build:pages` 或 `npm run build` 生成 `dist/`，可直接部署到 GitHub Pages。需要连同 `dist/assets/` 一起发布；HTML 本身可离线绘图和导出，但图片抠图需要通过 HTTP/HTTPS 加载后台线程与模型。`npm test` 执行渲染和轮廓测试。

## 图片导入和叠底

图片处理在浏览器后台线程运行，无需 Render、API 密钥或付费后端，照片不会上传。使用 ONNX Runtime Web 1.22.0 和 U²-Net 轻量模型（约 4.6 MB），首次抠图还需加载约 11 MB 的 WASM 运行库；模型会尝试保存到浏览器缓存，缓存不可用时仍可使用。模型来自 rembg 官方发布，构建时核验官方校验值。推理使用单线程 WASM，不要求 GitHub Pages 提供跨源隔离头。

支持浏览器可解码的 JPG、PNG、WebP 等图片，单文件最多 32 MB、4000 万像素。HEIC/HEIF 取决于浏览器支持，不支持时请先转换为 JPG。图片预览最长边缩小至 1024 像素，分割轮廓使用最长边 320 像素的掩码，保留最大连通主体，简化为最多 15 个顶点。透明背景图片直接使用 alpha，不下载模型。

轻量模型对复杂背景、细毛和多主体照片的效果可能弱于原来的 BiRefNet Lite，手机首次运行速度取决于设备。失败保留已有画面；重新导入或切换绘制、随机轮廓时会取消旧任务。

导入完成默认打开图片叠底。原图与多边形共享居中缩放变换，开关不改变轮廓。叠底打开时照片与小猫均保持完整不透明度，小猫遮盖轮廓内的原图。拖动顶点时底图固定；换猫保留底图；生成随机轮廓或完成新绘制后隐藏叠底。右上角“下载”按钮导出 1000×1000 PNG，包含已开启的底图，排除编辑点、按钮和姿态文字。

逐点绘制，点击起点或 Enter 完成；Backspace 撤销，Esc 取消。拖动顶点或整条边调整轮廓；双击边缘增加顶点，双击内部微调脸的位置。编辑控制点在鼠标悬停或触屏操作时显示。

旧 Python 图片处理服务保留供单独实验，但不是当前网页所需组件。若要运行旧服务，仍可按 `requirements.txt` 安装 Python 依赖，再执行 `.venv/bin/python server/serve.py`；当前网页默认使用浏览器抠图。

## 随机轮廓

角度限制已经取消。不显示最小角度，不补截角短边。随机轮廓从姿态轮廓扰动与自由径向多边形生成；仅检查边长、面积和自交以维持有效编辑，允许锐角、凹口和任意朝向。此前的颜色连通区抠图已移除；当前网页导入使用真实 U²-Net 轻量模型。

## 绘制

后台提供 58 个姿态预设（原有 50 个加 8 个参考图人工标注模板），用于轮廓对齐、镜像和匹配。预设库不在交互页面展示，也不提供姿势任意切换。匹配存在歧义，不代表真实动作识别。

眼睛与嘴巴独立随机组合，眼型支持睁眼、轻闭眼、眨眼、流泪和流汗。吐舌、泪滴、汗滴独立随机附加；好奇眼型保持三瓣嘴。面纹按猫的毛色和头部结构生成：虎斑从耳根延伸至眉间、眼角和脸颊；奶牛/三花使用连接耳根的色素分区；纯色猫只保留自然明暗。移除孤立的 W、三条直线、菱形及额头帽斑。无参数与五官文字控制器。

面部底色使用低透明度渐变融入身体，保留有意的奶牛、三花等色块；喷涂图层继续用 SVG 高斯柔焦；身体使用弯曲分叉条纹或深浅斑块。身体纹理在头部附近渐隐，避免随意穿过五官。轮廓内侧新增随光照方向变化的柔和渐变，仍裁剪在原始多边形内。画板右上角的 Material 下载图标可导出 1000×1000 PNG；开启图片叠底时包含底图，照片和小猫均不额外降低透明度，不包含编辑点、按钮及姿态文字。绘制未完成时暂时禁用下载。

## 验证

测试覆盖模板匹配、旋转/镜像、头部余量、自由随机轮廓、花色与额纹、独立眼口和吐舌/流泪/汗滴组合。浏览器端轮廓测试覆盖最大主体、孔洞、凹多边形和底图变换对齐。Chromium 实测透明 PNG、真实 WASM 抠图、无上传请求、叠底开关与 PNG 下载。HEIC 支持取决于浏览器。

最近渲染修正：身体花纹沿模板躯干布局，脸部区域用连续径向衰减过渡。所有模糊滤镜使用足够大的画布坐标范围，避免对象包围盒截断产生矩形接缝。重点色用渐变色素而非完整深色椭圆。内侧轮廓阴影由剪影透明度推导，不使用沿边缘描线。

参考图分类、实现范围及限制见 [第一批参考库](docs/reference-catalog.md)。构建后的 `pose-review.html` 提供人工轮廓与生成结果对比；高瘦且双耳明显的轮廓会额外检查脸部方向，照片毛色仍由随机配置生成。
