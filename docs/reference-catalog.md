## 当前落地范围

新增八个独立模板，连同原有五十个共五十八个。每个新增模板记录姿势家族、参考编号、轮廓、脸中心、脸朝上的点、身体色块和肢体阴影。轮廓是人工概括，不是对会话图片实际运行抠图后的坐标。

匹配仍以轮廓为基础；对高瘦轮廓中明显的顶部双耳凹口增加保守方向评分，减少转九十度套用侧卧模板。精确模板的旋转、镜像匹配以及拖动期间锁定模板保持支持。没有足够耳部证据时不猜测头部方向。

主画板毛色仍随机，尚未实现照片毛色提取或真实图像关键点检测。现有毛色库有十二种；补充素材中橘白、虎斑加白、双色重点色、长毛等差异作为后续毛色布局标签，不声称已实现全部组合。仅凭外轮廓无法可靠区分所有姿势。

## 对比检查

`npm run build:pages` 生成 `dist/pose-review.html`，展示两个独立失败轮廓及八个新模板的人工关键点与生成结果。旧失败轮廓基线分别为 sleep / -84.3° 和 hunt / -82.4°；均在修改前实测记录。对比页固定毛色以比较结构，不代表自动还原原图花色。

测试覆盖原问题、窄身变体、顶点起点与顺序变化、旋转、镜像、脸的位置／方向／余量、无耳轮廓不虚构头部线索。带服装、透明容器和截断肢体的图暂不加入普通全身匹配库。
